# ASG-OFFERS — инструкции для агентов (Claude / Codex)

Этот репозиторий раздаёт статические презентационные страницы под
конкретные предложения автомобилей (офферы) для B2B-покупателей через
GitHub Pages. Домен: **offers.asg-hub.com** (см. `CNAME`).

## Роль агента

Агент в этом репозитории — **публикатор готовых HTML-страниц**, не дизайнер.
Пользователь присылает готовый standalone HTML-файл (обычно сгенерированный
в Claude Design или аналогичном инструменте) под конкретный автомобиль.

Задача агента — только размещать эти файлы как есть:

- **Не редактировать** содержимое присланных HTML-файлов.
- **Не переписывать**, не "улучшать", не менять вёрстку/стили/тексты внутри.
- Только копировать файл на нужный путь, коммитить и пушить.

## Структура репозитория

```
/o/<slug>/index.html   — страница одного оффера
CNAME                  — домен GitHub Pages (offers.asg-hub.com)
README.md
AGENTS.md              — этот файл
CLAUDE.md              — подключает AGENTS.md для Claude Code
```

Каждый оффер живёт в собственной папке `/o/<slug>/` с файлом `index.html`
внутри. Итоговый URL оффера: `https://offers.asg-hub.com/o/<slug>/`.

## Правило генерации slug

- Длина: **6 символов**.
- Алфавит: буквы (латиница, нижний регистр) + цифры.
- Не должен быть последовательным или угадываемым (не `aaaaaa`, не `111111`,
  не `abc123`, не инкремент от предыдущих slug'ов).
- Перед использованием проверить, что папка `/o/<slug>/` ещё не существует
  в репозитории — при коллизии сгенерировать другой slug.

## Процесс публикации нового оффера

1. Сгенерировать новый slug по правилу выше.
2. Создать `/o/<slug>/index.html` с содержимым присланного файла без изменений.
3. Закоммитить и запушить в `main` (или в ветку, указанную в задаче).
4. Сообщить пользователю итоговую ссылку:
   `https://offers.asg-hub.com/o/<slug>/`

## Процесс удаления оффера

1. Удалить папку `/o/<slug>/` целиком.
2. Закоммитить и запушить в `main`.
3. Подтвердить пользователю, что ссылка деактивирована.
