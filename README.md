# ASG-OFFERS

Статические страницы автомобильных офферов ASG на GitHub Pages —
**offers.asg-hub.com**.

- `/` — каталог всех опубликованных офферов (генерируется, см. `AGENTS.md`)
- `/o/<slug>/` — страница одного оффера
- `templates/vehicle-offer-web/` — эталонный шаблон оффера

Публикация оффера — копирование присланной папки в `o/<slug>/` и пуш:
абсолютные URL для превью и каталог на корне дособираются автоматически
(`.github/workflows/offer-link-previews.yml`).

Процесс, правила slug'ов, требования к `share.jpg` и настройки каталога —
в `AGENTS.md`.

Пересобрать каталог локально: `node tools/build-catalog.mjs`
