# Бриф для Claude Design: витрина офферов ASG

Это задача на дизайн одной страницы. Текст ниже можно отдавать в Claude Design
как есть. Раздел «Контракт на выдачу» — то, без чего собранную страницу
придётся переделывать руками: генератор каталога подставляет карточки в
готовую вёрстку по меткам.

---

## Что делаем

Витрина всех актуальных автомобильных офферов ASG на корне домена
`offers.asg-hub.com`. Одна ссылка, которую отправляют брокеру или агенту
вместо семи отдельных ссылок на каждую машину.

Сейчас каждый оффер — отдельная страница `offers.asg-hub.com/o/<slug>/`,
собранная по нашей дизайн-системе (тёмный hero, Onest, оранжевый акцент,
палитра iron/mineral). Витрина должна читаться как часть той же системы, но
как другой тип страницы: оффер — это разворот про одну машину, витрина — это
полка.

## Для кого

B2B: брокеры, агенты, перекупщики. Смотрят с телефона и с десктопа, часто
из мессенджера. Сценарий один: открыть, пробежать глазами, кликнуть машину,
переслать ссылку дальше. Ни регистрации, ни корзины, ни форм — только полка
и переход в оффер.

## Что на странице

Шапка с логотипом ASG, счётчиком машин и датой обновления.
Заголовок и одна вводная фраза. Фильтр по марке. Сетка карточек. Футер с
дисклеймером про net-цены.

Карточка — самое важное. В ней:

| Поле | Пример | Заметки |
|---|---|---|
| фото | hero машины | соотношение 16:10, `object-fit: cover`; бывают и студийные рендеры на чёрном, и живые фото на светлом фоне |
| порядковый номер | `01` | поверх фото |
| марка | `Rolls-Royce` | оранжевый eyebrow, капс |
| модель | `Cullinan Series II Black Badge` | до ~45 знаков, бывает в две строки |
| спецификация | `Black Diamond · Mandarin · Left-hand drive` | до ~110 знаков, обрезается на второй строке |
| цена | `436,800 GBP` или `On request` | подпись `Net`; валюты GBP и EUR |
| статус | `Production November 2026`, `Availability to be confirmed` | до ~50 знаков |

Вся карточка — одна ссылка на страницу оффера.

## Ограничения, которые нельзя нарушать

- **Статика без сборки.** Один HTML + CSS (+ немного ванильного JS для
  фильтра). Никакого React, Tailwind, npm — страница лежит на CDN как файл.
- **Никаких внешних запросов.** Шрифты — локальным файлом, иконки — инлайн
  SVG. Google Fonts, CDN, аналитика запрещены: страница отдаётся с
  `Content-Security-Policy: default-src 'none'; script-src 'self'; style-src
  'self'; img-src 'self' data:; font-src 'self'`.
- **Относительные пути** для css/js/шрифтов.
- **Телефон в приоритете.** Одна колонка на мобильном, 2–3 на десктопе,
  боковые поля 20px на узком экране.
- Страница должна нормально выглядеть и на 1 карточке, и на 50.
- Тёмная тема. Светлой версии не нужно.
- `<meta name="robots" content="noindex, noarchive">` в `<head>`.

## Чего делать не надо

- Не придумывать цены, названия машин и тексты — они подставляются из данных.
- Не рисовать логотипы марок (Rolls-Royce, Ferrari и т.д.) — только текст.
- Не добавлять формы, чат, подписку, фильтры по цене и сортировки — этого
  пока нет в данных.

## Контракт на выдачу

Страница — не финальный файл, а **шаблон**: карточки в него подставляет
генератор (`tools/build-catalog.mjs`). Поэтому в выдаче нужны:

**1. Метки в разметке** — ровно такие комментарии, генератор заменяет всё
между ними:

```html
<!-- ASG:FILTERS:START -->
  <button class="chip is-active" type="button" data-filter="all">All vehicles</button>
  <button class="chip" type="button" data-filter="Rolls-Royce">Rolls-Royce</button>
<!-- ASG:FILTERS:END -->

<!-- ASG:CARDS:START -->
  <!-- здесь 3–4 карточки-примера с реальными данными из таблицы выше -->
<!-- ASG:CARDS:END -->
```

**2. Плейсхолдеры** в шапке — текстом, ровно в таком виде:
`{{COUNT}}` (число машин, например `07`) и `{{UPDATED}}` (дата, например
`18 Sept 2026`).

**3. Служебные атрибуты**, которые должны сохраниться на своих элементах:

- контейнер сетки — `id="grid"`;
- контейнер фильтров — `id="filters"`;
- пустое состояние («нет машин этой марки») — `id="gridEmpty"` с атрибутом
  `hidden`;
- каждая карточка — `data-brand="<марка>"` (по нему работает фильтр).

**4. Состояния**, которые нужно показать в выдаче: наведение на карточку,
активный чип фильтра, фокус с клавиатуры, карточка без цены (`On request`),
карточка с очень длинным названием модели.

**5. Файлы**: `index.html`, `catalog.css`, `catalog.js` (если нужен),
`assets/` со шрифтом и знаком ASG. Плюс отдельным файлом — шаблон
превью-карточки для мессенджеров, 1200×630: фото во весь кадр, затемнение
как в hero, знак ASG без подписи, заголовок слева внизу.
